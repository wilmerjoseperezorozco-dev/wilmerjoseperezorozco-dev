Centraliza cálculos con trazabilidad normativa real (NSR-10, NTC, RAS 2000, INVIAS, SG-SST), una base de precios propia con datos reales de obra, y reforzamiento sísmico de vivienda existente — construido y ampliado en vivo tras el terremoto de agosto de 2026.

## Cómo trabajo

- **Verbatim sobre resumen**: cuando construyo un sistema de consulta normativa, cito el texto exacto de la fuente oficial — nunca una paráfrasis que pueda alucinar un número.
- **Bajo costo, sin sacrificar rigor**: la mayoría de estos sistemas corren con modelos locales o hardware accesible (ESP32, embeddings locales) — la meta es que una solución real no dependa de un presupuesto que la mayoría de estas comunidades no tiene.
- **Sin inventar datos**: si una fuente no es verificable en vivo, se marca explícitamente como referencia — nunca se presenta como dato oficial.
